# Structural metadata

From v1.3, indicator **data structure definitions (DSDs)** and **codelists** are maintained in a **site-wide registry**. An indicator project **binds** to one data structure from the registry; observation data are imported and validated against that binding.

This section covers the registry. To attach a structure to a project and import data, see [Documenting indicators](/documenting_indicator.html).

## In this section

1. **[Managing codelists](/managing_codelists.html)** — Create and maintain standard controlled vocabularies.
2. **[Managing data structures](/managing_data_structures.html)** — Define DSD components; create structures from scratch or from a CSV file.

After a data structure exists in the registry, [attach it to an indicator project](/documenting_indicator_data_structure.html#attach-a-data-structure-to-the-project) and [import observation data](/documenting_indicator_import_data.html).
